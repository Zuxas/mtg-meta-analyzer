  MTG META ANALYZER — HOW TO USE
  by Team Resolve
=====================================================


GETTING STARTED (Step by Step)
=====================================================

Step 1: Build Your Database
  - First launch opens the Setup Wizard automatically
  - It downloads the Scryfall card database (~160 MB)
  - Then scrapes recent tournament data (takes a few minutes)
  - You need ~50 events before the dashboard works well

Step 2: Let It Run
  - Background tasks scrape new data automatically:
    * 6 AM daily — pulls from MTGTop8, MTGDecks, MTGMelee
    * 5 PM daily — latest Standard events + maintenance
    * Sunday midnight — refreshes Scryfall card data
  - The app lives in your system tray (green dot = current)

Step 3: Explore the Dashboard
  - Open the app and you land on the Dashboard
  - Pick your format (Standard, Modern, Pioneer, etc.)
  - Set a timeframe (2 weeks, 4 weeks, etc.)
  - Click Refresh to load the latest data

Step 4: Save Your Deck
  - Go to DECKS > MY DECKS
  - Click Add, paste your decklist, name it
  - Add sideboard plans for each matchup

Step 5: Track Your Results
  - Go to TOURNAMENT > MATCH LOG
  - Log each match: opponent deck, result, play/draw
  - Over time, your personal WR stats build up
  - Click "SB Advice" to see where you need to improve

Step 6: Prepare for Events
  - Go to TOURNAMENT > EVENT OPTIMIZER
  - Pick event type (RCQ, RC, PTQ)
  - Enter expected field or click "Use Meta Distribution"
  - See your top-cut odds and matchup breakdown


WHAT EACH TAB DOES
=====================================================

DASHBOARD
  The home screen. Three panels at the top:
  - Recent Top Finishes — latest tournament results
  - Win Rate — archetypes ranked by win % with Glicko-2
    ratings, prep priority, meta status, tier, and role
  - Popular — archetypes ranked by appearances

  Buttons:
  - Meta Shift — what changed since last period
  - Best Deck — recommends the best deck for this meta
  - Refresh — reload everything

  Charts below show Popularity or Win Rate Over Time.
  Check/uncheck archetypes. Toggle Daily/Weekly.
  "Show Events" marks set releases, bans, rotations.

  Double-click any archetype to see full details:
  average decklist, recent lists, tech choices, card trends.

-----------------------------------------------------

META (3 sub-tabs)
  Charts — Interactive charts: meta share, archetype
    trends, compare multiple decks, scatter plot, heatmap

  Matchup Data — The big win-rate grid.
    Shows how every archetype does against every other.
    Green text = favored, red = unfavored, grey = even.
    Star = real match data, no star = scraped.
    Right-click any cell to add team notes.
    "Gauntlet" builds a grid from top 12 meta decks.
    "Export Decks" exports decklists for mtg-sim testing.
    "Equilibrium" shows Nash optimal meta shares.

  Predictions — Auto-generated meta predictions
    and accuracy tracking over time.

-----------------------------------------------------

DECKS (2 sub-tabs)
  Analyze — Paste a decklist to get:
    - Blunder Detection (land count, curve, interaction)
    - Chapin Principles (Threats/Answers/Consistency/etc)
    - Legality Check (banned cards, deck size)
    - Auto-classify archetype (KNN machine learning)
    - Baseline Comparison (your list vs the average)
    - Deck Similarity (how close to meta archetypes)

    "Load Average Deck" fills in the stock list for any
    archetype so you can analyze or export it.

  My Decks — Save your decklists and sideboard plans.
    - Add/Edit/Delete decks
    - Sideboard Plans per matchup (play/draw IN/OUT)
    - Export (MTGO, MTGA, decklist.org)
    - Export Guide (printable HTML for tournament day)
    - Share JSON / Import JSON (share with teammates)

-----------------------------------------------------

SEARCH (3 sub-tabs)
  Card Browser — LOCAL Scryfall search. Works offline.
    Searches all 37,000+ cards in the Scryfall database
    stored on your machine. No internet needed.

    Search syntax (combine any of these):
      t:creature         type contains "creature"
      o:"draw a card"    oracle text search
      c:red              color filter
      ci:wub             color identity
      cmc<=3             mana cost comparison
      f:standard         format legality
      r:mythic           rarity filter
      is:legendary       supertypes
      k:flying           keyword abilities
      pow>=4             power comparison
      tou<=2             toughness comparison
      s:tdm              set code filter

    Examples:
      t:creature c:red cmc<=2 f:standard
      o:"destroy target" ci:wb r:rare
      k:lifelink pow>=3 f:modern

    Card detail panel shows: full image, oracle text,
    legalities, meta usage stats, Similar Cards
    (text-based), and Functional Substitutes (usage-based).

    "Cards in Meta only" toggle filters to cards that
    actually appear in competitive decklists.

  Deck Search — Find tournament decklists by archetype,
    player name, or format. Click to see full list.

  Head-to-Head — Compare two archetypes with win rates
    and matchup history.

-----------------------------------------------------

TOURNAMENT (2 sub-tabs)
  Event Optimizer — Prepare for specific events.
    1. Pick event type (RCQ/RC/PTQ/Custom)
    2. Select your deck (or load a saved one)
    3. Enter the expected field
    4. Get: top-cut probability, X-loss cutoff,
       matchup breakdown, SB recommendations,
       encounter probability per opponent

    The Breaker Math sub-tab inside has:
    - Live W/L/D tracker during events
    - ID calculator (safe to draw?)
    - Draw equity calculator
    - Pair-down warnings
    - Seeding impact explanation
    - Tiebreaker education

  Match Log — Track your tournament results.
    - Log each match with opponent, result, play/draw
    - Stats table: Your WR vs Meta WR per matchup
    - Green delta = outperforming, Red = underperforming
    - "SB Advice" button: identifies your weakest matchups
      and suggests sideboard changes based on guides
    - Win rate trend chart over time

-----------------------------------------------------

RESOURCES (1-3 sub-tabs)
  Guides & Bookmarks — Sideboard guides synced from
    Skill Issue Magic sheet + your saved bookmarks.

  Ask Claude (needs API key in Settings) — Chat with
    Claude AI about meta, card choices, strategy.
    Has live meta context from your database.

  Set Analysis (needs API key) — Analyze new set
    spoilers. Fetch from Mythic Spoiler, classify each
    card by competitive impact per archetype.

-----------------------------------------------------

SETTINGS
  - Formats — pick which formats to scrape
  - Storage — DB size, event counts, collect more data,
    scan for cross-source duplicate events
  - ML Models — download embeddings, train Card2Vec/KNN
  - API Key — for Ask Claude and Set Analysis


TIPS
=====================================================

- Hover over buttons and column headers for tooltips
- Double-click any archetype name to see the full detail
  dialog (average deck, recent lists, tech choices)
- Right-click heatmap cells to add team notes
- The app stays in your system tray when you close it
  (right-click tray icon > Exit to fully quit)
- "Export Decks" on Matchup Data exports average lists
  as .txt files compatible with mtg-sim for testing
- Card Browser works completely offline after first
  Scryfall download — it's your local card search engine
